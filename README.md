# S3 컴플라이언스 모니터링 시스템

## 프로젝트 개요
Terraform으로 생성된 S3 인프라의 퍼블릭 엑세스를 CloudTrail로 설정 변경을 추적하고,
IAM 유저의 과도한 권한을 탐지하는 클라우드 보안 컴플라이언스 모니터링 시스템

## 배경
S3 퍼블릭 액세스는 조작 몇 번으로 쉽게 설정 해제가 가능한 반면
데이터 노출, 조작 및 랜섬웨어 등 치명적인 결과를 초래할 수 있습니다. 
신속한 변경 탐지 및 추적이 가능한 시스템은 이를 방지해
S3 버킷의 데이터를 안전하게 지킬 수 있습니다.

IAM 유저가 수행하는 작업에 비해 너무 과도한 권한을 지닐 경우
불필요한 서비스의 접근을 초래해 인프라에 악영향을 미칠 수 있습니다.
최소 권한 원칙(Least Privilege)에 따라 권한을 탐지하고 관리합니다

## 아키텍처
Terraform

└── S3 버킷 생성 (퍼블릭 액세스 차단, KMS 암호화, 버전 관리, 로깅)

boto3 + FastAPI

├── /s3-status       → S3 퍼블릭 액세스 설정 실시간 조회

├── /trail-history   → CloudTrail 설정 변경 이벤트 추적

└── /iam-status      → IAM 과도한 권한 탐지

## 탐지 시나리오
1. terraform으로 퍼블릭 액세스가 차단된(기본값) S3 버킷 생성
2. 해당 버킷 설정 권한자가 실수나 의도적으로 퍼블릭 엑세스 허용으로 변경
3. /s3-status에서 퍼블릭 액세스가 허용된 상태를 감지
4. /trail-history에서 차단 설정 혹은 해제됐을때 당시의 설정을 변경한 권한자, 대상 버킷이름, 시간, 변경상태가 담긴 이벤트를 추적함
5. /iam-status에서 IAM 유저, 유저의 소속 그룹, 정책 목록을 가져와 해당 유저가 보안을 위협할 과도한 권한을 가지지 않았는지 확인함

## 기술 스택
- Terraform : 자동화, 버전관리 등을 용이하게 해주는 직관적인 IaC
- Trivy     : 현재 유지보수가 중단된 tfsec의 기능을 흡수한, 배포 전 환경 취약점을 확인해주는 보안스캐너.
- boto3     : 인프라 자동화 및 파이썬 코드 만으로 다양한 AWS 서비스 접근 가능
- CloudTrail: AWS 서비스에 대한 보안사고 대응 및 규정 준수
- FastAPI   : 신속한 처리 속도, 간결함, 반복 작업 최소화 및 생산성 극대화
